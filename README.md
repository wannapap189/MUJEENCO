# MUJEEN Frontend

เว็บไซต์ MUJEEN ฉบับเผยแพร่ล่าสุด: https://mujeen-art-preview.enjoyableheath1.chatgpt.site

Static frontend สำหรับแบรนด์ MUJEEN ใช้ HTML, CSS และ JavaScript พร้อมภาพ ฟอนต์ และวิดีโอที่หน้าเว็บใช้งานจริง ไม่ต้องติดตั้งแพ็กเกจหรือมีขั้นตอน build

## เปิดในเครื่อง

ใช้ Node.js 20 หรือใหม่กว่า แล้วรัน:

```sh
npm start
```

เปิด http://127.0.0.1:8140/ และให้ terminal นี้ทำงานระหว่างดูเว็บ

ตรวจลิงก์และไฟล์ภายในด้วย `npm run check`

## โครงสร้าง

| เส้นทาง | เนื้อหา |
| --- | --- |
| `index.html` | หน้าแรกภาษาไทย |
| `collection/` | คอลเลกชัน |
| `devotion/` | วิชาและพิธีกรรม |
| `stories.html` | บันทึกและเรื่องราว |
| `worship/menshen/` | เทพประตู |
| `en/` | ภาษาอังกฤษ |
| `zh/` | ภาษาจีนตัวย่อ |
| `zh-hant/` | ภาษาจีนตัวเต็ม |
| `assets/` | โลโก้ ภาพ ฟอนต์ และสคริปต์แกลเลอรี |
| `videos/` | คลิปที่ใช้บนเว็บไซต์ |

ไฟล์ HTML เป็นหน้าเว็บที่แก้ไขได้โดยตรง เมื่อแก้เนื้อหาให้ตรวจฉบับภาษาอื่นที่เกี่ยวข้องด้วย CSS และ JavaScript อยู่ที่โฟลเดอร์หลักและ `assets/`

## ติดตั้งบนโฮสติ้ง

อัปโหลดไฟล์ HTML, CSS, JavaScript, `assets/`, `videos/` และโฟลเดอร์หน้าเว็บไปยัง document root ของโฮสต์ static ที่รองรับ HTTPS และ `index.html` ไม่ต้องอัปโหลด `scripts/`, ไฟล์ Git หรือไฟล์สำหรับนักพัฒนา

เว็บใช้ลิงก์สัมพัทธ์ จึงรองรับทั้งการติดตั้งที่โดเมนหลักและ subdirectory ควรให้โฮสต์รองรับ HTTP Range Requests เพื่อเลื่อนตำแหน่งวิดีโอได้

ไม่มี backend ระบบรับชำระเงิน หรือฐานข้อมูล ฟอร์มติดต่อเชื่อมไปยัง LINE @mujeen ที่ https://lin.ee/qufgtB8

## ขอบเขตเนื้อหา

- MUJEEN เป็นแบรนด์ของคอลเลกชัน แยกบทบาทจาก อ.แขก มันตระสยาม และสถานที่สักการะให้ชัดเจน
- ข้อมูลวัสดุ ขนาด และการจัดส่งให้สอบถามทีมงานผ่าน LINE
- ช่องทางโซเชียลที่ยังไม่ได้ระบุลิงก์คงสถานะรอข้อมูลจริง
- ชุดนี้ไม่รวมเอกสารภายใน ไฟล์ต้นฉบับงานวิจัย หรือการตั้งค่าบัญชีโฮสติ้ง

ภาพ วิดีโอ โลโก้ และเนื้อหาเป็นสื่อของโครงการ MUJEEN การนำไปใช้ภายนอกโครงการต้องได้รับอนุญาตจากเจ้าของสิทธิ์
